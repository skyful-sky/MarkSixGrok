## 3. 鎖定八注映射

候選輸出排列 `r_t[1..N]`；分數方向在模型登記中鎖定，同分一律小號優先。若訓練本身用亂數，演算法／版本及唯一種子 **20261030** 先登記，不搜索種子。候選必須明確定義輸出入選集合排序的推導，不能只得到已入選球的出場次序再冒充入選率。

固定八注位置模板，b=0..7、j=0..5：

```text
T_(t,b) = { r_t[1 + ((6*b+j) mod N)] : j=0..5 }
```

每注六個不同主號；八注整組不得重複。各 N 的固定結構如下，所有數字均為**排名位置，不是已產生的預測號碼**：

- N=43：前七注為 1–6 至 37–42；第八注為 `{43,1,2,3,4,5}`。八注有重疊，不能稱八注不重疊。

## 4. 公平基準：精確配置機率

公平虛無為每期獨立、從 N 個主號均勻無放回選 m 個；它是檢定假設，不是對任何設備已被證明公平的宣告。對已固定八注配置 T：

```text
q(N,m,T) = #{D⊂{1..N}: |D|=m, max_b |D∩T_b|≥3} / C(N,m)
```

不能把八張單注成功率直接相加，也不能用 `1-(1-p_single)^8` 當作精確值，因各注事件相依且可能重疊。均勻虛無下，同一模板經任意號碼排列，其覆蓋數不變；因此逐期歷史適應排序仍有同一個條件公平 q。額外球不參與本事件，雙色球此表**不乘藍球 1/16**。

本版全部使用**精確整數組合計數，沒有 Monte Carlo 誤差**。方法是按「出現在哪些注」的 8 維 membership 向量分組，組大小為 a，選 k 球的組合權重為 `C(a,k)`；動態規劃追蹤已選總球數與八注命中數，丟棄任一注已達 3 的狀態。最後取總球數 m、每注≤2 的係數 F，成功數即 `C(N,m)-F`。這等價於展開：

```text
∏_(n=1..N) (1 + z ∏_(b:n∈T_b) x_b)
```

取 z 次數 m 且每個 x 次數≤2 的係數和。49 球八注不重疊另可用容斥獨立核對：`8*Σ_(h=3..6) C(6,h)C(43,6-h) - C(8,2)C(6,3)^2`；六球最多讓兩注各命中三碼。

為防止每批重設α，本協議預先採**跨提交的 Bonferroni 額度分配**，不是把「第15次」機械乘15，也不在結果後選 Holm 或另一校正：

```text
四個固定彩票槽 ℓ=1..4；未來提交 j=1,2,...
α_(j,ℓ) = 0.05 / [4*j*(j+1)]
Σ_j Σ_ℓ α_(j,ℓ) = 0.05
```

缺來源、撤回或失敗的槽位不回收額度、不轉給別國；同一提交只評一次。對固定 500 期命中數 K，主檢定是單側 `P[Binomial(500,q)≥K]`，門檻 `p≤α_(j,ℓ)`；同時報告同一α的單側 Clopper–Pearson下界。只有在逐期公平獨立虛無、模板固定且保留窗有效時，才有這個錯誤控制；多重比較校正不能補救先看結果再改模型、未登記機制閘門或歷史來源偏差。上述0.05只規範此後合格、完整登記的外部檢定，不替過往未知次數探索作追溯保證。

本版不另做以機制 p 值決定進退的統計閘門；球組輪替／槽位等資料或推導資格須在開跑前固定。日後若另設統計閘門，其統計量、方向、門檻、次數及共同錯誤額度須先明列，不能反覆改閘門或以其顯著取代命中檢定。輔助機制 p 值不得充當下節通過條件。

## 6. 「穩定高於基準」的固定申請條件

**同一候選、同一固定版本至少在四個彩票中的兩個不同彩票，全部滿足以下條件，才可向 Manager 申請動用香港 attempts：**

1. 資料及事前登記／保留窗資格全過；500 期完整，無漏期、事後出票、移窗或模型回調。
2. 五個連續 100 期區塊的命中率**各自嚴格高於該彩票 q**，不能只挑最好一段。這是方向穩定性篩選，不是五個獨立確認性證明。
3. 全 500 期成功率至少 `q+0.02`（**2 個百分點**，不是2%相對增幅）。
4. 全 500 期單側精確二項 p≤預留α，並且同一α的單側 Clopper–Pearson下界**嚴格高於 q**。等於 q 不算通過；有離散邊界相等時以此較嚴條件為準。不能用平均排名、次序顯著、效應方向、文獻 p 值或公平配置模擬替代。
