# 日本Loto6的A–J尚不能認定為穩定實體球組

本輪官方查核可確認抽選機型及東京／大阪會場安排，**未取得A–J與實體球組序號、批次、後備組替換及機台序號的逐期對照台帳**。因此目前沒有可認證為同一批實體的世代區間，合資格區間0、合資格期數0；不是原資料沒有觀測，也不是已證明球組必定在各期更換。依賴「A–J代表穩定實體」的discovery-only分層外部校準，現階段應停在資料核實，不執行校準或模型。

只核實資料；沒有建模、預測、候選ID或新attempt，累計仍14次。所有取得時間為UTC，詳見補充目錄的`sources.json`；本文件和補充檔均附SHA-256。

## 停止條件及可否外部校準

目前停止**依賴同一實體球組／機台的校準**。合資格同世代區間清單為空，各字母合資格期數均0；不是以事後成績挑選區間，也不因未找到公告就默認沒有更換。

要解除本資料缺口，至少須有可追溯官方資料，把字母、會場、球批／實體識別及生效期次連起來，並能界定後備組替換、補球、換機及暫時搬場。區間內出現未解替換、來源會場衝突、NA或無法對應的ID時，停止該實體分層的使用；保留缺值，不猜字母沿用，也不換窗口湊樣本。若日後方法需要開獎前球組資訊，還須另外核實當時公開時間，事後列表不構成事前可用證據。

這個判定只針對本次待核實的實體前提，**不修改或重跑已封存的CAL-EXT-GAP1-RAND-v1**，也不自動改變其他外部協議。純字母標籤的描述與實體球偏機制是不同問題；本輪只核實資料，沒有執行任何新校準或授權預測。
