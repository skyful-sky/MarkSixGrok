Manager另授權一次[CAL-EXT-GAP1-RAND-v1描述性校準](../../docs/cal-ext-gap1-rand-v1.md)：只用本探索目錄，首200期暖身、其後最多500期；韓國135／雙色球92不足暖身，不能借用封存資料。SSQ原始期號另附`ordinal`，存取介面的target參數對SSQ使用累計ordinal；紅球1–33及獨立藍球1–16可同值。以下原版「三份」係前輪快照範圍，本輪加第四份；原三份CSV雜湊保持不變，全部來源資格及封存限制繼續適用。

以上是與前版預期主號矩陣一致、且不跨本輪已核明分界的**保守探索範圍**；完整歷史矩陣及機球一致性仍未核實，不能把它升格為全部操作制度相同的證明。日本／韓國不為湊1,000期跨已知規則或營辦安排轉換；沒有按號碼分布或候選成績選擇截點。更早未列出的實體制度改變仍屬資料缺口。

三份均實際取得所有固定期次，缺期0；日本／韓國採來源明列回號，UK年度頁期號是日期排序索引，另用詳頁的印出701／1700核對邊界。`main_pool_expected`是預期49／43／45，不是當期總球數的直接觀測。`n1`–`n6`只含升序主號，`extra_ball`獨立存檔，不參與主指標。全部結果來自原已列備用站，未冒作官方完整逐期核對。

缺結果時，原期次保留`NA`及`status=missing`／原因；未知日期也NA，不補球號、不由星期推日期、不拿後一期補洞、不延長終點。若UK年表少列且無法定位未印期號的缺口，正規化器停止，不能把後面的日期重新編號。不能把NA槽數冒作有效觀測數。

HTTP原文採無損gzip另存[`docs/review-evidence/discovery-source-snapshots/`](../../docs/review-evidence/discovery-source-snapshots/)。完整年度頁可能附有1–700或探索終點以後的其他期次，**這些原文只供取得審計，並非探索輸入，禁止探索程式讀取**；只有本目錄三份已截取的CSV屬允許探索集。日本最後一頁按46列請求，沒有為湊頁面將1147以後納入CSV。31次請求中28次保存內容，3次SSL／403失敗均留錯誤原文摘要；HTTP200另檢查內容，不自行升格為官方核驗。

[`prepare_discovery.py`](../../docs/review-evidence/prepare_discovery.py)是離線取得審計工具，只解析新原文，沒有分析／評分功能，也不讀`data/external/`結果；可由保存原文逐位元組重現CSV。`access.py`是探索程式應用的受限讀取介面：只接受`uk`／`japan`／`korea`鍵，不接受檔案路徑；核對固定範圍、雜湊及NA，不開啟原文或封存CSV，並拒絕越界符號連結。`history_before(key,t)`只回傳探索集內`issue<t`的行，包含NA槽，不回傳第t期或以後結果。

此介面會為校驗讀完整探索CSV，再交出受限前綴；**不是盲測逐期揭示器**。它是應用程式的邊界檢查，不是作業系統權限隔離；另寫Python或直接讀git歷史仍可繞過，不能藉測試聲稱資料重新未曝光。沒有新增評分程式；未來實作者須另行接入並通過同樣邊界測試，不能以此聲稱未存在的評分器已獲驗證。

完整使用／封存及反向時間洩漏限制見[探索與封存窗口分離](../../docs/discovery-holdout-split.md)。本輪保護檔、原`data/external/`全部位元組、registry及tags均不改，attempts仍14/20。
